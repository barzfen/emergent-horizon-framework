# OPW–AMP bridge: XBR source archive

Recovered source package, 2 November 2026. [Sources and result notes](sources/) cover the available XBR-01–05C progression: shared middle-block growth, chart transport, adjacency intertwining obstructions, Krylov closures, invisible complements, rational representation classification, and the null-channel holonomy stopping result.

Read the later result notes with the earlier scripts. Fixed or versioned implementations are retained without rewriting their predecessors. Seven Python files carry UTF-8 byte-order marks; Python accepts these when reading source bytes. The originals have not been altered to remove them.

Two important historical limits are retained:

* No direct full-image adjacency intertwiner was obtained in the tested nonzero AMP channels; the invariant closure can be much larger than the starting image.
* The audited exact primitive/fixed-multiplicity null-channel support graphs are forests. No qualifying ordinary reversible holonomy loop was constructed in that n=9 category. This is a failure of the required transport structure, not a computed trivial holonomy.

The term invisible is relative to a specified algebraic map or generated subspace, not a claim of physical unobservability. These are finite operator and representation results, not derived particles or gauge fields.

No original XBR run has been revalidated merely by recovering its source. Not all generated certificates or scripts for every named substage are present.
