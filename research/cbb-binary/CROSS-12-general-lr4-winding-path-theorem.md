# EHF-CBB-CROSS-12 — General balanced three-colour LR4 winding-path theorem

Date: 2026-11-10. Status: constructive theorem, with local LR4 increment lemma verified by exhaustive 42-pattern audit.

## Setup
An oriented proper cyclic three-colour word w of length n=3m has m copies each of A,B,C and no equal neighbouring colours. Define sigma(A,B)=sigma(B,C)=sigma(C,A)=+1 and opposite transitions -1. Define signed winding W(w)=(sum of all cyclic edge signs)/3, an integer.

The winding-transition quotient graph has vertices all attained signed winding values and an undirected edge between distinct W-values if at least one admissible LR4 reversal takes a balanced proper word at one value to a balanced proper word at the other. This is **not** the full configuration graph.

## Theorem
For every integer m>=2, the LR4 winding-transition quotient graph on balanced proper cyclic three-colour words of length n=3m is the path

-m -- -m+2 -- ... -- m-2 -- m.

## Proof
1. For any proper cyclic word, 3W=N+-N- and N++N-=3m. Thus |W|<=m, and W is congruent to m mod 2. Therefore all possible winding values lie in {-m,-m+2,...,m}.
2. Construct C_p=(ABC)^p(ACB)^(m-p) for each p=0,...,m. Every block contains A,B,C once, begins with A, ends with B or C; concatenating blocks cyclically is proper and balanced. Each ABC block contributes +3 to the total signed edge sum when counting its two internal edges and the boundary edge to the next block's A; each ACB contributes -3. Hence W(C_p)=p-(m-p)=2p-m. All allowed winding values are realized.
3. For p<m, the first ACB block of C_p begins at cyclic index 3p. Its four-vertex segment (the ACB block followed by the initial A of the next block, cyclically) is A,C,B,A. Reversing these four vertices gives A,B,C,A, and changes that block from ACB to ABC while leaving the next block's initial A unchanged. The resulting cyclic word is exactly C_(p+1). The operation is admissible since both C_p and C_(p+1) are proper. This also works at p=m-1 by wrapping to the first A of the cyclic word.
4. By the LR4 local lemma, any admissible LR4 reversal changes W by exactly +/-2, so no nonconsecutive winding levels can be adjacent in the quotient graph. Steps 2 and 3 provide every consecutive edge. QED.

## LR4 local lemma (42 cases)
For a six-letter proper neighbourhood L,a,b,c,d,R with L!=d and a!=R, reverse a,b,c,d. The signed winding difference is always +/-2. Enumerating all 3^6 assignments yields exactly 42 admissible neighbourhood patterns: 21 with +2 and 21 with -2. This finite exhaustive audit is a machine-checkable lemma. A fully symbolic case split could replace it.

```python
from itertools import product
from collections import Counter
counts=Counter()
for w in product(range(3), repeat=6):
    if any(w[i]==w[i+1] for i in range(5)):continue
    v=(w[0],)+tuple(reversed(w[1:5]))+(w[5],)
    if v[0]==v[1] or v[4]==v[5]:continue
    sign=lambda x,y: 1 if (y-x)%3==1 else -1
    d=sum(sign(v[i],v[i+1])-sign(w[i],w[i+1]) for i in range(5))
    assert d%3==0
    counts[d//3]+=1
assert counts==Counter({-2:21,2:21}), counts
print(counts)
for m in range(2,10):
    def wind(w):
        n=len(w)
        return sum(sign(w[i],w[(i+1)%n]) for i in range(n))//3
    for p in range(m):
        w=(0,1,2)*p+(0,2,1)*(m-p)
        n=len(w)
        ix=[(3*p+j)%n for j in range(4)]
        v=list(w)
        for j,z in zip(ix,reversed([w[t] for t in ix])):v[j]=z
        target=(0,1,2)*(p+1)+(0,2,1)*(m-p-1)
        assert tuple(v)==target and wind(v)==wind(w)+2
print('constructive witnesses checked m=2..9')
```

## Scope and limits
The theorem proves connectedness of the **winding-level quotient**, not connectedness of all balanced proper words under LR4. For n=9, labelled-cycle LR4 retains a parity obstruction and has two components (CROSS-07). The theorem does not imply a universal 1:2:3 ratio, or an SU(3) gauge-group correspondence. It demonstrates a universal one-dimensional ladder of winding levels generated by a local reversal.
