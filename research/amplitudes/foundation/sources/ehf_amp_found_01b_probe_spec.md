# EHF-AMP-FOUND-01B: True All-Anchor Residue Closure

## Status

Internal EHF/RAF bridge probe.

This probe corrects and supersedes the archived AMP-20 closure test. The old test changed the collinear reference leg but retained the anchor-1 source-fibre partition, then used a wide QR decomposition that automatically completed the candidate columns to the full ambient space. Its near-zero closure residual was therefore not a valid span-membership result.

AMP-18 remains independently reproduced:

- all 35 target fibres at `n=8` have relation dimension 15;
- anchor-1 residues from `n=9` generate 15 dimensions in 34 fibres;
- the exceptional fibre
  
  `E={1,4,5,6}, O={2,3,7,8}`
  
  receives only 14 dimensions;
- the rank-14 decision has a large singular-value gap.

The open question is whether **genuine re-anchoring of the source charts** recovers the missing direction.

---

## Research question

For every source anchor `a = 1,...,9`:

1. rotate each canonical `n=9` Hamilton cycle so `a` is the comparison reference;
2. reflection-reduce relative to `a`;
3. rebuild the parity-position partition `Pi_a`;
4. recompute the local Parke–Taylor relation space of every `Pi_a` fibre;
5. take residues only in channels collinear with the same anchor `a`;
6. transport the residue vectors into one common canonical `n=8` ordering space;
7. combine the anchor-relative images using rank-aware SVD orthogonalisation.

Does the cumulative all-anchor residue span contain the exceptional fifteenth target relation?

---

## Formal object

Let

`R_(9,a,C)`

be the local constant-coefficient Parke–Taylor relation space on source fibre `C` in the anchor-`a` chart. Let

`partial_(a,j): R_(9,a,C) -> R_8`

be the collinear residue deleting leg `j` adjacent to anchor `a`, transported into the common `n=8` canonical ordering coordinates.

For an anchor set `A`, define

`I_A = span { partial_(a,j)(R_(9,a,C)) : a in A, C in Pi_a, j adjacent to a }`.

Let `v_*` be the unique relation direction in the exceptional 15-dimensional target fibre relation space not generated by the anchor-1 local residue image.

The primary diagnostic is

`delta_A = ||(I - P_(I_A)) v_*|| / ||v_*||`.

Closure means `delta_A < 1e-6`, with a large numerical margin expected if the result is genuine.

---

## Mandatory validity checks

A closure verdict is accepted only if all of the following pass:

1. **Anchor-spectrum covariance**  
   Every anchor-relative `n=9` chart has the same multiset of `(fibre size, relation dimension)` pairs as anchor 1.

2. **Local relation total**  
   Every anchor has the same total local relation dimension as anchor 1.

3. **Fresh residue identity check**  
   Each completed anchor residue span and the cumulative span annihilate fresh independent `n=8` Parke–Taylor samples below the configured tolerance.

4. **Global dimension bound**  
   The cumulative residue rank may not exceed the expected global `n=8` constant-coefficient relation dimension:

   `2520 - 6! = 1800`.

5. **Rank-aware membership**  
   Span construction uses incremental SVD orthogonalisation. Wide QR completion is forbidden.

6. **Basis-invariant target containment**  
   The script reports the principal-angle intersection dimension between the cumulative residue span and the full 15-dimensional exceptional relation space, not merely the projection of one chosen basis.

## Pre-registered outcomes

### Outcome A: true all-anchor closure

- cumulative missing residual falls below `1e-6`;
- exceptional intersection dimension becomes `15/15`;
- fresh Parke–Taylor residual remains below tolerance.

Interpretation: the missing target relation is invisible to one comparison chart but reconstructed by gluing genuine anchor-relative charts. This would support the **comparison-atlas** interpretation.

It would not by itself show that EHF derives gauge theory.

### Outcome B: partial improvement without closure

- the residual decreases materially but remains nonzero;
- exceptional intersection remains `14/15`.

Interpretation: re-anchoring carries complementary information, but the tested collinear residue family is insufficient to generate the full target relation space.

### Outcome C: no meaningful improvement

- residual remains near the anchor-1 value;
- intersection stays `14/15`.

Interpretation: the exceptional direction is not generated by odd-to-even local collinear residues, even after genuine chart rebuilding. It may be intrinsically even-multiplicity, require another factorisation operation, or indicate a real obstruction to the gluing conjecture.

### Outcome D: all-anchor global relation generation

- cumulative rank reaches 1800 with valid fresh relation residuals.

Interpretation: all anchor-relative local residue spaces generate the entire global `n=8` constant-coefficient relation space. This would be stronger than exceptional-fibre closure and would become the principal result.

## Recommended first run

```bash
caffeinate -i python3 scripts/ehf_amp_found_01b_true_all_anchor_residue_closure.py \
  --base-script scripts/ehf_amp_found_01_reproduce_amp18_20.py \
  --base-run-dir runs/ehf_amp_found_01_amp18_20 \
  --out-dir runs/ehf_amp_found_01b_true_all_anchor_seed11 \
  --seed 11
```

The existing anchor-1 caches in `runs/ehf_amp_found_01_amp18_20/cache` will be reused. Anchor-specific caches for anchors 2 through 9 are written beneath the new output directory.

Interrupted runs can be restarted with the same command.
