# EHF-HC-03 · Vertex connectivity and Hamiltonian completion

**COMPUTATIONAL.** The first stable-colour completion disagreements with a biconnected residual graph occur at nine residual vertices, or twelve vertices in the full input. There are seven failing residual graphs and nineteen failing marked configurations at that size. Two-vertex separator tests with one step of lookahead at both terminals recover the exact feasible entry sets in those nineteen configurations.

**PROVED / NEGATIVE.** Stable colour refinement can fail at every prescribed vertex connectivity $k\ge2$. A four-connected example on fifteen residual vertices defeats both the separator tests and their one-step lookahead.

## Setting and smallest counterexamples

Use the [HC-02 comparison](HC-02.md#comparison-rule). The residual graph $H$ contains the unvisited vertices. Its marked set $A$ contains the possible exits back to the original route's root. An entry vertex is feasible if a spanning path of $H$ can start there and end in $A$. Stable colour refinement fails for the completion decision if a class contains both a feasible and an infeasible entry. Here biconnected means $H$ has at least three vertices and remains connected after deleting any single vertex.

### Turn a set of exits into one terminal

Add a vertex $z$ adjacent exactly to $A$, and mark only $z$ in the new graph. An original vertex can start a spanning path ending at $z$ exactly when it could start a spanning path ending in $A$ before the addition. Deleting $z$ from a spanning path exposes its predecessor in $A$. Conversely a spanning path ending in $A$ extends by one edge to $z$.

The old stable classes together with the singleton $\{z\}$ are an equitable partition, meaning each vertex of a class has the same neighbour count into every class. Adjacency to $z$ is uniform on each old class because $A$ was marked before the addition. Conversely, the new stable partition restricted to the old vertices is equitable there and respects membership in $A$, since different adjacency to the marked $z$ splits a class. Thus the stable classes on the old vertices are exactly preserved. For a connected $H$ of order at least two and nonempty $A$, the new graph is biconnected exactly when every component of $H-v$ meets $A$ for each original vertex $v$. If a component has no attachment to $z$, it stays disconnected when $v$ is removed. Otherwise the surviving attachments reconnect all the components through $z$.

Both eight-vertex examples of HC-02 meet this condition with $A=\{0,1,2,3,4,5\}$. Recall triangles $(0,3,6)$ and $(2,5,7)$ joined by $6$–$1$–$4$–$7$, and the variant with edge $6$–$7$. The new terminal is $z=8$. A spanning path from $0$ to $8$ is $(0,3,6,1,4,7,2,5,8)$. The same stable class contains $1$, which cannot start a spanning path ending at $8$. After deleting $8$, the two terminal triangles each require an endpoint away from their attachment vertex. The full input adds the visited triangle on $(r,p,q)$, with edges $r$–$8$, $p$–$0$ and $q$–$1$ into the residual graph. Prefixes $(r,q,p)$ and $(r,p,q)$ now give different completion answers under the same stable attachment counts. The census below establishes minimality because distinct endpoints on the same visited set require at least three visited vertices.

## What two-vertex cuts recover

For an exact proposed terminal pair $(x,y)$, deletion of a separator $S$ from a spanning path leaves at most $|S|+1-|S\cap\{x,y\}|$ nonempty path segments. Each component of $H-S$ needs at least one segment. If all slots are needed and both terminals survive, they must lie in different components, since each component then contains exactly one segment. This is an endpoint-sensitive form of the component-count obstruction that also underlies scattering number. [Broersma et al. (2015), introduction](https://research.utwente.nl/files/6777296/Broersma_et_al-2015-Journal_of_Graph_Theory.pdf)

For a finer test on a cut $S=\{a,b\}$, contract every component of $H-S$ to a token. In either order of $a,b$, each of the three gaps in the spanning path contains either no vertices or a run from one component. Enumerate these layouts, requiring all components to occur, respecting adjacency to the cut vertices and between them, and using a component at most as many times as it has vertices. A terminal pair must project to a feasible layout for every cut. The contracted test leaves the paths inside each component unresolved.

These tests both miss $(x,y)=(1,8)$ in the lifted example with the $6$–$7$ edge. The two cuts are $\{6,8\}$ and $\{7,8\}$. In each contracted graph, the component containing $1$ can go first, then the remaining cut vertex, then the other component, then $8$. Both projections are allowed even though a real spanning path from $1$ to $8$ is impossible.

### Look one edge beyond the terminals

If a spanning path from $x$ ends at $y$, then after deleting $y$ it must still have a feasible pair $(x,z)$ for some neighbour $z$ of $y$. Use the separator conditions for that pair on $H-y$. Apply the requirement in both directions, holding the original pair $(x,y)$ fixed. Each endpoint is deleted separately. Every true spanning path survives, since it supplies both witnesses. For a root-marked entry decision, keep $x$ if some $y\in A$ passes the same pair of tests.

| Component counts and terminal placement for cuts of size at most two | 8 | 10 |
| Contracted layouts for the two-vertex cuts | 8 | 10 |
| Contracted layouts, then delete either terminal and check cuts of size one | 16 | 18 |
| Contracted layouts, then delete either terminal and check cuts of size at most two | 19 | 19 |

The right column only concerns entries wrongly grouped with a feasible one. The middle column checks all entries in the graph.

## Counterexamples at any connectivity

Let $D$ be the eight-vertex HC-02 residual graph with two triangles joined by a three-edge path. Vertex $0$ can start a spanning path of $D$. Vertex $1$ cannot, since both bridges incident to it would have to be used. The vertices share a stable class with no markings.

For $k\ge2$, take the disjoint union of $D$ and $k-1$ isolated vertices. Add a clique $S$ of $k$ new vertices, joining every clique vertex to every vertex outside it, and mark one clique vertex $y$ as the sole allowed exit. The resulting residual graph has $2k+7$ vertices and connectivity exactly $k$. A clique vertex survives the removal of fewer than $k$ vertices and connects everything left. Removing the entire clique leaves $k$ components.

For an entry $x$ in $D$, a spanning $x$–$y$ path yields at most $k$ nonempty runs after the clique is deleted because $y$ is its terminal. All $k$ components require a run, so $D$ occurs in one uninterrupted run starting at $x$. Hence $x$ must start a spanning path of $D$. Conversely such a path extends by alternating clique vertices and the $k-1$ isolated vertices, finishing at the marked clique vertex. The original stable classes in $D$, the isolated vertices, and the two clique classes distinguished by the mark form an equitable partition. Therefore refinement still equates the feasible entry $0$ with the infeasible entry $1$.

For $k=4$ the above gives a fifteen-vertex residual graph. There is no cut of size one or two, even after deleting either terminal, since at least one clique vertex still survives those deletions. Both terminals have neighbours other than each other, so the bad pair $(1,y)$ also passes the lookahead. More generally, for cuts of size at most $b$ and the same one-step lookahead, choose $k\ge b+2$.

It compares the separator controls with the exact spanning-path endpoint sets from the [HC-02 verifier](verify_hc_02.py) and independently checks the small higher-connectivity constructions.
