# EHF-HC-04 · Exact path composition across a separator

**PROVED.** For a fixed vertex separator and proposed endpoints, spanning-path feasibility is exactly the compatibility of ordered visits and disjoint local path covers. At a two-vertex separator, a component needs at most two visits, and at most one component can need the second visit.

**NEGATIVE.** Requiring a single visit can discard a valid spanning path on five vertices. Allowing each visit to be chosen independently and checking that the lengths add up can give a false positive on five vertices. Checking that every vertex occurs in some candidate of the chosen lengths can still give a false positive on six vertices. These orders are minimal for the three tests at a two-vertex separator.

**COMPUTATIONAL.** Exact composition agreed with the whole-graph oracle in 1,395,742 comparisons across all two-vertex cuts of connected graph shapes through order eight. It also agreed on the earlier nine-vertex residual counterexamples and on the 13- and 15-vertex examples with higher connectivity.

## Exact composition rule

Use the [Hamiltonian completion setting](HC-03.md#setting-and-smallest-counterexamples). Let $H$ be the graph of the unvisited vertices. Fix distinct proposed endpoints $x,y$. For a nonempty vertex separator $S$ of size $k$, write $C_1,\ldots,C_c$ for the connected components of $H-S$.

1. Choose the order in which the path encounters the vertices of $S$. A terminal in $S$ forces that end of the order and leaves its outer gap empty.
2. Assign each gap before, between, and after these vertices either to a component or to no vertices. Each component occurs at least once. A terminal outside $S$ fixes the component in its outer gap. An empty internal gap requires an edge between the consecutive cut vertices.
3. For each component, list the nonempty vertex sets that can support each of its assigned visits. For a visit next to a cut vertex, the corresponding end of its internal path must be adjacent to that cut vertex. For a visit containing a terminal, the end is fixed to that terminal. A visit may be a single vertex.
4. For each component choose one set from each visit's list, so the sets are pairwise disjoint and together cover the component.

**Necessity.** Reading a spanning path from $x$ to $y$ yields a separator order, and cutting the path at those vertices produces precisely the internal paths in the chosen gaps. A gap with vertices in two different components would require an edge between the components. Within each component the gaps partition its vertices.

**Sufficiency.** Choose a witnessing internal path for each selected vertex set and concatenate them through the cut vertices in the given order. The attachment requirements supply all join edges. The disjoint covers and the single occurrence of each cut vertex make the concatenation a spanning simple path with the stated endpoints.

The subset path table stores which starts are possible for each vertex subset and final vertex. An attachment query reads that table to return the possible vertex sets for a single visit. A second subset calculation in each component combines only disjoint choices and checks that their union is the full component. For a marked exit set $A$, an entry $x$ is feasible exactly when the test accepts at least one $y\in A$ with $y\ne x$ in the nontrivial residual graphs considered here.

### Specialisation to a two-vertex cut

There are at most three nonempty gaps and at least two components. With three components, all visits are single. With two components, there can be one repeated component and it can occur only twice. If either endpoint lies on the cut, there are at most two nonempty gaps and so every component has just one visit. Thus the only extra local calculation beyond spanning paths inside single components is whether **two** visits can use complementary vertex sets within one component.

More generally, the number of available gaps is $k+1-|S\cap\{x,y\}|$. When this equals the number of components, each component is visited once. In the [HC-03 clique separator construction](HC-03.md#counterexamples-at-any-connectivity) with an exit on the clique, exactly this saturation occurs. The composition test sees the need for one uninterrupted path through the original eight-vertex component.

## What three simpler tests lose

In the examples below the separator is $\{0,1\}$ and the proposed path runs from $2$ to $3$. Every graph in the table is biconnected.

| Simplification | Vertices | Edges | Incorrect decision |
| --- | ---: | --- | --- |
| Allow only one visit per component | 5 | 02, 04, 13, 14, 23 | Rejection |
| Use independent visits whose lengths sum to the component size | 5 | 02, 03, 04, 12, 13, 24 | Acceptance |
| For the same length choice, also require every vertex to occur in the union of the possible sets | 6 | 02, 03, 13, 14, 15, 24, 25 | Acceptance |

In the five-cycle of the first row, $2,0,4,1,3$ is a spanning path. The component $\{2,3\}$ contains both terminals, so that component has to occupy both outer gaps with $\{4\}$ between them.

In the second row, both cut orders require two visits to $\{2,4\}$, since the two outer gaps are occupied and edge $01$ is absent. The two visits must each have length one in vertices. The first contains $2$, and the between-cut visit can also choose $2$ since it is adjacent to both cut vertices. Vertex $4$ has no edge to $1$, so the two singleton visits cannot cover $\{2,4\}$. The lengths add up even though the same vertex was used twice.

In the six-vertex example, $\{2,4,5\}$ induces a path with centre $2$. For cut order $0,1$, the first visit can use $\{2\}$ and the middle visit can use either $\{2,4\}$ or $\{2,5\}$. All three vertices occur among the candidates at those lengths, with lengths one and two summing to three. Every middle visit uses $2$ because $0$ attaches to this component only there. That holds for the reverse cut order too. No middle visit can be combined disjointly with the first visit, which must contain $2$.

**Minimality.** A two-vertex cut with at most four total vertices leaves only singleton components, and the length condition rules out repeating a singleton. At order five a repeated component has at most two vertices and at most two visits. If repeated, both visits have length one. Two nonempty singleton menus whose union covers both vertices always permit a distinct choice, so the union test is exact through order five. These bounds and the three witnesses give the claimed minimal orders.

Exact composition passed all 1,008 comparisons at the 28 two-vertex cuts of the seven minimal biconnected HC-03 graphs. This gives the exact decision for all nineteen marked choices without one-step lookahead. It also matched the whole-graph subset solver at every endpoint pair for the three- and four-connected clique examples, with 78 and 105 comparisons respectively at their designated clique cuts.

For a supplied cut and fixed endpoints, there are at most $k!(c+1)^{k-1}$ gap assignments including the separator orders, because both outer gaps are determined. The local subset tables have $\sum_i 2^{|C_i|}$ rows. In the 15-vertex example the component sizes are $8,1,1,1$, giving 262 rows across the local tables versus 32,768 in a whole-graph table. This is a table-size comparison. The total search also depends on the separator orders and the costs of joining disjoint local choices.

The separation of local path packings from their boundary connectivity is standard in Hamiltonian dynamic programming on decompositions. Cygan, Kratsch and Nederlof store boundary degrees and matching connectivity in their path-decomposition algorithm. Bodlaender et al. use rank to compress representative partial solutions. This probe uses a single supplied separator to identify exactly where the HC-03 approximations lose information. [Cygan, Kratsch and Nederlof (2018), §4](https://doi.org/10.1145/3148227) · [Bodlaender et al. (2015)](https://arxiv.org/abs/1211.1505)

## Reproduce

Run from the repository root with Python 3.12. The first command checks the witnesses without a download. The optional census uses McKay's graph6 data under CC BY 4.0, retrieved on 17 November 2026. The concatenated files from orders three through eight in ascending order had SHA-256 `e0cf8402e3d7c8696a020716dd2f2b324b694a3a35a544115f8e9b263c7bd597`. [Catalogue licence](https://users.cecs.anu.edu.au/~bdm/data/)

```sh
python3 research/hamiltonian-cycle/verify_hc_04.py

catalogues=$(mktemp -d)
for order in 3 4 5 6 7 8; do
    curl -fLsS "https://users.cecs.anu.edu.au/~bdm/data/graph${order}c.g6" \
        -o "$catalogues/graph${order}c.g6" || exit
done
python3 research/hamiltonian-cycle/verify_hc_04.py "$catalogues"/graph[3-8]c.g6
```

The next comparison is whether joint visit compatibility can be compressed into boundary pairings that stay exact when several separators are composed. This probe was prepared with AI assistance. Priority of the minimal examples has not been evaluated.
