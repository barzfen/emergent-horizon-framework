# EHF-HC-02 · Stable neighbour refinement and Hamiltonian completion

**PROVED / NEGATIVE.** Repeated neighbour refinement distinguishes the two routes in the [HC-01 square](README.md#smallest-failure-of-the-attachment-counts). It can still give two routes with different completion answers the same signature. Two families of counterexamples persist through arbitrarily many rounds, including a family with no residual bridges.

**COMPUTATIONAL.** The minimum is eight residual vertices, or eleven vertices in the full graph. The census checked every connected residual graph up to isomorphism through order eight and covered all choices of root attachment. Exactly two residual graphs fail at order eight.

## Comparison rule

Use the fixed graph, root $r$ and unvisited set $U$ of [HC-01](README.md#exact-comparison). Write $H=G[U]$, $A=N_G(r)\cap U$ for the possible exits back to the root, and $B=N_G(t)\cap U$ for the possible entries from the current endpoint $t$. Mark the vertices in $A$. Start with the labels $(\deg_H(v),\mathbf{1}_{v\in A})$. Each round replaces a vertex's label with its previous label and the multiset of its neighbours' previous labels. Stop once no class splits. These are the stable classes of colour refinement starting with the membership marks. Including degree in the initial labels reaches the same final partition, since degree is already determined by the first round from membership alone. This is the established one-dimensional colour-refinement procedure applied within a single marked residual graph. [Berkholz, Bonsma and Grohe (2017), abstract and introduction](https://doi.org/10.1007/s00224-016-9686-0)

The proposed search key counts the members of $B$ in each stable class. In the square of HC-01, the good entry is adjacent to the marked exit and the bad entry is opposite it. The first refinement round separates them.

Let $F$ consist of the vertices of $H$ from which a spanning path can finish at a vertex in $A$. A partial route can finish when $B\cap F$ is nonempty. For any fixed $(H,A)$, the stable counts determine that Boolean answer for all possible $B$ exactly when $F$ is a union of stable classes. If each class is wholly inside or outside $F$, the count tells us whether $B$ meets any class inside $F$. If a class is mixed, singleton entry sets drawn from opposite sides of the class have matching counts and different answers.

## An explicit eleven-vertex counterexample

Use a residual graph $H$ on vertices $0$ through $7$. Take triangles $(0,3,6)$ and $(2,5,7)$ joined by the path $6$–$1$–$4$–$7$. Mark $A=\{0,1,2,3,4,5\}$.

| Initial class | Neighbour counts within the two classes | Can start a spanning path ending in $A$? |
| --- | --- | --- |
| Marked vertices $0,1,2,3,4,5$ | One marked, one unmarked | Yes for $0,2,3,5$. No for $1,4$. |
| Unmarked vertices $6,7$ | Three marked, zero unmarked | No |

The labels are already stable. Vertex $0$ has the spanning path $0,3,6,1,4,7,2,5$ ending in $A$. Vertex $1$ cannot be an endpoint of a spanning path. Each incident edge at $1$ is a bridge, and a spanning path must traverse every bridge. In the second example add edge $6$–$7$. The marked vertices still have the same neighbour counts, and both unmarked vertices gain one unmarked neighbour. Every edge now belongs to a cycle, so the residual graph is bridgeless. A spanning path still needs one endpoint in each terminal triangle away from its attachment vertex. Each triangle can be entered and left only via its attachment vertex, which a simple path can visit once. Thus the displayed path remains valid and $1$ still cannot start a completion.

To obtain the full input graph, add the visited triangle on $r,p,q$. Connect $r$ to $A$, $p$ to residual vertex $0$, and $q$ to residual vertex $1$, with no other edges from the triangle to $H$. The prefixes $(r,q,p)$ and $(r,p,q)$ then have the same residual set and equal singleton attachment counts. The prefix ending at $p$ can finish and the prefix ending at $q$ cannot. Both residual examples also fail when all eight vertices are marked.

### Families surviving every round

For any $L\ge3$, take two disjoint cycles of length $L$, choose one attachment vertex on each, and join those vertices by a path of length $L$ with new interiors. Mark every vertex other than the two attachments. The attachment vertices make one class. Group the other vertices by distance along their length-$L$ cycle or joining path to the closer attachment. Each distance class has the same neighbour counts at every vertex, including the midpoint for even $L$ and the two central vertices for odd $L$. It follows by induction that refinement never separates a cycle neighbour of an attachment from its joining-path neighbour. A spanning path can start at the former, traverse that cycle to its attachment, take the joining path, and traverse the last cycle. Every edge of the joining path is forced by a bridge, so its first interior vertex cannot start a spanning path.

Adding a direct edge between the two attachments preserves these classes and removes all bridges. Each terminal cycle still requires one endpoint away from its attachment, so the same disagreement persists. Both families have $3L-1$ residual vertices and give full input graphs with $3L+2$ vertices by the visited-triangle construction.

### A cut-vertex control

In a connected residual graph, deleting a vertex on a spanning path leaves at most two path segments. If deletion produces more than two components, no spanning path exists. If it produces exactly two, the two endpoints of any spanning path must lie in opposite components. Testing all such cuts keeps exactly the feasible entry vertices for both minimal examples and both failing mark choices. These tests give necessary conditions in general. The bridgeless example shows why a test using only edge bridges would be insufficient.

## Census and reproduction

For each connected residual graph representative, the verifier computes possible finishes from every entry by exact subset dynamic programming. It tests all root-attachment masks that could mix feasibility in a stable class. For an ordered pair $(x,y)$ in the same unmarked class, a candidate $A$ must intersect the finishes from $x$, avoid all finishes from $y$, and mark both $x,y$ or neither. Refining from any marked partition cannot merge already-distinct unmarked classes, so these conditions omit no possible conflict. An independent check enumerated all nonempty masks, used direct path enumeration for endpoint feasibility, and agreed on the counts. The [Python verifier](verify_hc_02.py) also tries every literal suffix order on the full eleven-vertex examples.
