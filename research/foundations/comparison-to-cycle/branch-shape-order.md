# Can a tree supply the order of its swaps?

**Date** 18 November 2026, Australia/Brisbane  
**Status** Exact tree results and bounded verification.  
**Prerequisite** [Local swaps produce a cyclic order](README.md#can-a-comparison-network-generate-a-single-cycle).

## Read each branch from its attachment point

Admissible comparison is the chosen primitive data of the framework. In this model the comparison relation is a finite undirected tree. At a site $v$, removing $v$ separates its incident branches. Each neighbour $u$ is the root of one branch. Give that branch a shape code by wrapping the sorted codes of its child branches in parentheses. A leaf has code `()`. Recursing shows that two codes match exactly when the rooted branches are isomorphic. This uses the standard bottom-up idea from rooted tree isomorphism. The encoding here is a simple verifier implementation. [Anna Lindeberg, *Isomorphism Testing of Rooted Trees in Linear Time*, 2024](https://arxiv.org/abs/2401.07636).

The code can also travel across edges as a message. The message $u\to v$ waits for messages $w\to u$ from all neighbours $w\ne v$. Those dependencies concern strictly smaller branches, so any delivery order that eventually delivers ready messages gives the same codes. The messages need recognisable incident links and a rule for combining the messages on them. A simultaneous clock or a numerical ranking of vertex identities is unnecessary for this procedure. The general problem of what anonymous network processors can infer from local structure is classical. [Dana Angluin, *Local and Global Properties in Networks of Processors*, 1980](https://doi.org/10.1145/800141.804655).

Choose a fixed total ranking of rooted shape codes. At every vertex, run incident swaps in order of the shapes of the branches they enter. If their shapes differ, this orders them with no labels. If some shapes agree, allow all tie orders. The [first probe](README.md#what-can-an-observer-reconstruct) shows that each assignment of local orders is feasible and determines a directed successor cycle.

## Unique cycles and interchangeable branches

**Exact criterion.** A bare tree supports a deterministic, relabelling-equivariant choice of a directed cycle on its actual vertices exactly when every vertex has distinct incident branch types.

If all branch types differ at every site, the chosen ranking gives one order and hence an equivariant cycle. If two branches of a vertex have the same rooted shape, the tree has a nontrivial automorphism that fixes this vertex and exchanges the branches. Any equivariant directed cycle would commute with this automorphism. Since the automorphism fixes one vertex on that cycle, commutation forces it to fix its successor and every subsequent vertex. That contradicts the branch exchange.

Equivalently, the automorphism group acts without fixed vertices for every nonidentity element. With a single tree centre that requires a trivial automorphism group. With a central edge, the group can also have order two, generated by exchanging the endpoints of that edge. These statements follow from the standard centre of a tree, which is a vertex or an edge and is preserved by every automorphism.

**A second exact statement.** For a fixed ranking of shapes, all allowed tie resolutions yield the same pair of tree and directed cycle up to a tree automorphism. Thus the bare tree and the ranking do determine one observable output for an observer who identifies symmetrically equivalent vertices.

To prove it, root the tree at either centre for the argument. An automorphism fixing a vertex fixes the chosen centre. In the central-edge case a vertex is closer to one central endpoint, so fixing that vertex prevents exchanging the two centres. Therefore at a non-root vertex the branch toward the root has a unique code. Otherwise an automorphism fixing the vertex could exchange that branch with a different one and move the chosen centre. All ties are between child branches. Compare two tie resolutions by matching the sorted children in order, including the chosen order within each tied class, and continue recursively. Since matched child subtrees have equal shapes, this defines a rooted tree automorphism. It carries the full local orders to each other. The parent branch sits at the same ranked slot because its shape is preserved and has no tie there. The resulting automorphism also carries one successor cycle to the other.

For instance, the three leaves of a star can be sequenced six ways at the hub. The six labelled successor maps differ, while they give a single shape once symmetries of the tree identify the interchangeable leaves.

## Two limits on the reconstruction

- **Scope of comparison.** Give a single hub three arms of lengths $L,L+1,L+2$. The full tree is asymmetric. Within the induced ball of radius $L$ the arms all look the same, and they first all become distinct at radius $L+2$. There is no uniform fixed radius that suffices even on these asymmetric trees. Message passing can accumulate the required distinctions over larger regions.
- **Choice of ranking.** Take arms of lengths 1, 2 and 3. Sorting by branch size puts them in order 1, 2, 3. An even-first ranking, with size as the next criterion, puts them in order 2, 1, 3. Both depend only on branch shapes. Their resulting cycles on the same tree are distinct even if orientation reversal is identified. The comparison relation supplies the distinctions and the ranking decides how to use them.

The fixed comparison tree, its incident links, persistence of sites, the one-swap-per-edge rule, and a common ranking are inputs to this experiment. A cycle is the effective successor map after one round of swaps. Its edges represent combined transport. The results concern when anonymous structure supplies event order and when an observer's equivalence removes the remaining ambiguity.

## Verification

Run `python3 research/foundations/comparison-to-cycle/check_branch_shape_order.py`. The verifier generates unlabelled trees through 14 sites by leaf attachment and rooted-code deduplication. Shape totals agree with [OEIS A000055](https://oeis.org/A000055). Of the 3,159 shapes at 14 sites, 151 have distinct branch types at every site. On all tree shapes of orders 2–8, it checks both first-ready and last-ready message delivery and independently compares the actual successor maps for 6,305 tie resolutions under tree automorphisms. The three-arm controls check the radius and the two rankings.
