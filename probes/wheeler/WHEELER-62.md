# WHEELER-62 — Minimal-Seed Entropy / Symmetry Bound Audit

**Date:** 19 October 2026 (Australia/Brisbane). **Status:** PROVED for the specified minimal four-run seed; exact algebraic certificates and finite implementation checks.

**Outcome:** starting from `(2,2,2,2)`, ordinary rotation-class Shannon entropy increases **strictly at every growth event**, for all time. Its leading growth is `3 log₂ t + O(1)` bits. This preparation-specific theorem coexists with WHEELER-61's counterexample for a different deterministic seed.

## 1. Scope and theorem

Keep event-uniform zero-cost MICRO growth and identify rotations only. Use four-run notation

`(a,b,c,d) = [0^a 1^b 0^c 1^d]`,

with `(a,b,c,d)` equivalent to `(c,d,a,b)`. Reflections and bit exchange remain distinct. Begin at the single class `(2,2,2,2)`, of size 8 and D=4, and retain the complete unconditioned endpoint law at every event count t.

Let C_t be the current rotation class. Then:

**For every integer t≥0, `H(C_(t+1)) > H(C_t)`.**

Moreover,

**`H(C_t)=3 log₂ t+O(1)` as t tends to infinity.**

The second statement is an asymptotic bound on the entropy itself; it does not assert an exact formula or a pointwise asymptotic for each one-step increment. Event count is the time parameter here, not a derived physical clock.

## 2. Separate ordered uncertainty from symmetry

Let R_t retain the four run labels of the seed. Write their extension counts as x₁,…,x₄, summing to t. From the urn law proved in [WHEELER-61](WHEELER-61.md),

`P_t(x) = product_(i=1..4) binom(x_i+2,2) / binom(t+11,11)`.

This law is invariant under swapping the two run pairs. A rotation class has two equally likely ordered representatives unless the run vector is periodic, `(u,v,u,v)`, in which case it has one.

Write ρ_t for the probability of this periodic case. The exact entropy identity is

`H(C_t)=H(R_t)−1+ρ_t`,

so

`ΔH(C_t)=ΔH(R_t)+ρ_(t+1)−ρ_t`.

At odd t the total size 8+t is odd, so a twofold repeated run pattern is impossible and **ρ_t=0**. Only an even-to-odd transition can subtract a periodicity correction. The proof will bound that correction against the entropy generated by the ordered dynamics.

## 3. A lower bound on ordered-run entropy production

At source size n=t+8, an ordered run of length ℓ_i is extended with probability `(ℓ_i+1)/(n+4)`.

Fix an ordered target y of size n+1. Its possible predecessors are obtained by decrementing a coordinate y_i≥3. That predecessor contributes probability `y_i/(n+4)`. Hence every column sum of the ordered kernel is at most

`c_t=(n+1)/(n+4)=(t+9)/(t+12)<1`.

A row-stochastic kernel with column sums at most c obeys

`H(output)−H(input) ≥ −log₂ c`.

For completeness, put `s_y=sum_x K(x,y)` and `q_y=sum_x p_x K(x,y)`. Convexity of `f(u)=u ln u`, applied with weights `K(x,y)/s_y`, gives

`q_y ln(q_y/s_y) ≤ sum_x K(x,y) p_x ln p_x`.

Sum over y and use the row sums to obtain

`H(q)−H(p) ≥ −sum_y q_y log₂ s_y ≥ −log₂ c`.

Unreachable targets with s_y=0 contribute nothing. Applying this to the ordered run kernel proves

**`ΔH(R_t) ≥ log₂[(t+12)/(t+9)]`.**

We will also use the elementary strict bound

`log₂[(t+12)/(t+9)] > 3/(t+12)`.

Indeed, `ln(1+x)>x/(1+x)` for x>0 and `ln 2<1`; substitute x=3/(t+9).

## 4. Exact periodic-class probability

At t=2m, periodicity requires `x₁=x₃=u` and `x₂=x₄=m−u`. Therefore

`ρ_(2m) = [sum_(u=0..m) binom(u+2,2)^2 binom(m−u+2,2)^2] / binom(2m+11,11)`.

The generating function

`sum_(u≥0) binom(u+2,2)^2 z^u = (1+4z+z²)/(1−z)^5`

follows by expanding the degree-four coefficient polynomial, or by multiplying the series by `(1−z)^5`. Squaring it gives the numerator generating function

`(1+8z+18z²+8z³+z⁴)/(1−z)^10`.

Thus the convolution numerator is

`binom(m+9,9) + 8 binom(m+8,9) + 18 binom(m+7,9)`

`+ 8 binom(m+6,9) + binom(m+5,9)`.

Binomial coefficients with nonnegative top smaller than bottom are zero. Simplifying yields the closed form

**`ρ_(2m) = 495 P(m) / [4 D(m)]`,**

where

`P(m)=m⁴+12m³+53m²+102m+84`,

`D(m)=(2m+1)(2m+3)(2m+5)(2m+7)(2m+9)(2m+11)`.

In particular, ρ₀=1 and ρ₂=3/13. The code verifies the closed form as an exact polynomial identity, independently of finite sampling.

## 5. The all-m bound

For every integer m≥2,

**`ρ_(2m) < 3/(2m+12)`.**

Since all denominators are positive, this is equivalent to

`G(m)=2D(m)−165(m+6)P(m)>0`.

Set u=m−2≥0. Direct expansion gives

`G(u+2) = 128u⁶ + 3675u⁵ + 42260u⁴ + 246615u³`

`          + 756542u² + 1112940u + 543510`.

Every coefficient is positive. Hence G(m)>0 for all real m≥2, which proves the required integer bound. This is an algebraic sign certificate, not an extrapolation from tested values.

## 6. Complete proof, including the early steps

There are four cases.

**First step, t=0.** The initial class is deterministic. The next class is `(2,2,2,3)` or `(2,2,3,2)`, each with probability 1/2: one extends a one-run and the other a zero-run. These are distinct because bit exchange is not identified. Thus H(C₀)=0 and H(C₁)=1 exactly.

**Odd t.** Here ρ_t=0 and ρ_(t+1)≥0, giving

`ΔH(C_t) ≥ log₂[(t+12)/(t+9)] + ρ_(t+1) > 0`.

**The remaining early even step, t=2.** Here ρ₂=3/13 and ρ₃=0. Since `14⁴ > 2×11⁴`,

`log₂(14/11)>1/4`.

Consequently,

`ΔH(C₂) ≥ log₂(14/11)−3/13 > 1/4−3/13 = 1/52 > 0`.

**Every even t=2m≥4.** Combine the ordered entropy bound with the polynomial bound:

`ΔH(C_(2m)) ≥ log₂[(2m+12)/(2m+9)]−ρ_(2m)`

`                    > 3/(2m+12)−ρ_(2m) > 0`.

These cases cover every nonnegative integer event count. Strict monotonicity is proved.

The early-step handling is necessary: the simpler rational bound on ρ fails at m=0 and m=1. The proof does not silently extend it there.

## 7. A quantitative entropy-growth law

Summing the ordered entropy bound from step 0 to t−1 telescopes:

`H(R_t) ≥ log₂[(t+9)(t+10)(t+11)/(9×10×11)]`.

Using the symmetry identity yields

**`H(C_t) ≥ log₂[(t+9)(t+10)(t+11)/990]−1+ρ_t`.**

For an upper bound, count the possible ordered extension vectors: `binom(t+3,3)`. Under pair exchange, the number of fixed vectors is t/2+1 when t is even and zero otherwise. Pairing the nonfixed vectors gives the exact number of rotation classes

`N_t = [binom(t+3,3) + I_(t even)(t/2+1)]/2`.

Every such class is reachable with positive probability. Hence

**`H(C_t) ≤ log₂ N_t`.**

Both bounds are `3 log₂ t+O(1)`. This proves the claimed leading entropy growth. The coefficient three comes from four run-extension counts subject to their fixed-sum constraint; it is not evidence for three-dimensional physical space.

The periodicity correction itself has the exact even-time asymptotic

`ρ_t ~ 495/(64 t²)` for even t,

and is zero for odd t. This follows directly from the leading terms of P and D. The correction becomes small faster than the ordered entropy-production lower bound, which is of order 1/t.

## 8. Relationship to the previous counterexamples

WHEELER-60 disproved universal ordinary quotient-entropy monotonicity over arbitrary preparations. WHEELER-61 disproved it even over all deterministic single seeds, using `(2,100,2,100)`.

Neither claim is restored here. This theorem establishes strict monotonicity for **one specified minimal seed and its actual unconditioned endpoint law**. The distinction is mathematical, not a change of measure or observation rule.

The mechanism is now explicit. In both cases, ordered-run uncertainty grows. For some seeds, the loss of the periodicity correction can exceed that gain. For `(2,2,2,2)`, the all-time bounds prove it cannot.

Rooted entropy, inherited orbit-weighted entropy and accumulating history entropy retain their earlier conclusions. No thermodynamic interpretation is needed for this preparation-specific ordinary Shannon theorem.
